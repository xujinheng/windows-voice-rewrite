# VoiceRewrite v0.1.1

Voice typing and AI-assisted text editing for Windows 11, plus an **experimental, currently unstable** macOS build.

## Start here · 新手安装

1. Download **Qwen3-ASR-OneClick-Windows-x64.exe**. Double-click, let it download Qwen3-ASR and llama.cpp automatically, and keep the window open when it says **READY!**.
2. Download **VoiceRewrite-Setup-0.1.1-x64.exe**. Double-click to install; no ZIP extraction is required.
3. Click a text field. **Hold Mouse4 (lower mouse side button)** to talk; release to dictate.

中文详细图文入门 / Chinese-first quickstart: [README](https://github.com/xujinheng/windows-voice-rewrite/blob/v0.1.1/README.md). English: [English guide](https://github.com/xujinheng/windows-voice-rewrite/blob/v0.1.1/README.en.md).

## Downloads

- `Qwen3-ASR-OneClick-Windows-x64.exe` — Windows x64 speech-model auto-installer and server; **double-click, no extraction**.
- `VoiceRewrite-Setup-0.1.1-x64.exe` — Windows x64 installer; **double-click, no extraction**.
- `VoiceRewrite-windows-x64.zip` — portable Windows client; **extract first**, then run `VoiceRewrite.exe`.
- `VoiceRewrite-0.1.1-macOS-arm64-Experimental.zip` — **unstable** Apple Silicon menu-bar app; extract `VoiceRewrite.app`.
- `VoiceRewrite-0.1.1-macOS-x86_64-Experimental.zip` — **unstable** Intel Mac menu-bar app; extract `VoiceRewrite.app`.

## Notes

- Windows defaults: OneClick ASR at `127.0.0.1:8080/v1` with model `qwen3-asr`. It downloads Qwen3-ASR-1.7B with the bf16 projector and detects CUDA or CPU. Internet access and several GB of free storage are needed on first run.
- For rewriting/translation/AI text actions (Mouse5), install [LM Studio](https://lmstudio.ai/), download a chat model, start its local API server, and verify the text model connection in Settings. Basic dictation (Mouse4) needs only OneClick.
- **macOS is experimental and currently unreliable** for dictation, clipboard insertion and editor compatibility. No OneClick for Mac: users must separately configure an ASR server and the JSON config. The Mac ZIPs are ad-hoc signed development packages, **not Apple Developer ID signed or notarized**. macOS may block launch; check the download origin and system safety prompts.
- The Windows installer is not publisher-signed; Windows SmartScreen may warn. These are real platform-security limitations, not errors to ignore.
- Voice and text are sent to your configured model endpoints. See [Privacy](https://github.com/xujinheng/windows-voice-rewrite/blob/v0.1.1/PRIVACY.md).

The project includes significant cross-platform Go Core reuse, Qwen3-ASR configuration fixes and improved macOS fallback behavior, but macOS physical input reliability still requires testing.
